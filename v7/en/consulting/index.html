Authorization becomes architecture

A path from simple claims to relationships

Add precision as your product evolves. Select a stage to explore.

01 / A CAPABILITY

Claims

Start with feature access or simple capabilities expressed as actions.

can('read:project');
can('update:project');
can('manage:workspace');

A stable API for simple permissions, ready to gain resource context when you need it.

02 / ADD A RESOURCE

Actions / Subjects

Give every layer a shared vocabulary: what action, on which resource?

can('read', 'Project');
can('update', 'Project');
can('manage', 'Workspace');

The same capability vocabulary now distinguishes articles, projects, and workspaces.

03 / GROUP PERMISSIONS

RBAC

Map roles to rules once, instead of scattering role checks across features.

can('read', 'Project');
if (user.role === 'projectAdmin') can('update', 'Project');
if (user.role === 'workspaceAdmin') can('manage', 'Workspace');

Roles become bundles of action/resource permissions.

04 / ADD CONTEXT

ABAC

Refine permissions with ownership, tenant identity, or resource state.

can('read', 'Project', { tenantId: user.tenantId });
if (user.role === 'projectAdmin') {
  can('update', 'Project', { tenantId: user.tenantId });
}
if (user.role === 'workspaceAdmin') {
  can('manage', 'Workspace', { tenantId: user.tenantId });
}

Roles can still grant permissions; attributes constrain which records those grants cover.

05 / FOLLOW RELATIONSHIPS

ReBAC

Add workspace membership and resource administrator relationships on top of tenant isolation.

can('read', 'Project', {
  tenantId: user.tenantId,
  workspaceMemberIds: { $in: [user.id] }
});

can('update', 'Project', {
  tenantId: user.tenantId,
  projectAdminIds: { $in: [user.id] }
});

can('manage', 'Workspace', {
  tenantId: user.tenantId,
  workspaceAdminIds: { $in: [user.id] }
});

Denormalized: Fast, local permission checks. Requires keeping derived membership attributes synchronized.

Complementary models, not mandatory migrations. RBAC, ABAC, and relationship-derived permissions can coexist.
