# Project logos

Original SVG assets used solely to identify projects in the “Built with CASL”
section. Brand colors and geometry are unchanged. These marks remain the property
of their respective owners; inclusion does not imply sponsorship or endorsement
in either direction. Sources checked on 2026-10-27.

| Asset | Official source | Usage / license reference |
| --- | --- | --- |
| strapi.svg | https://automatic-life-0194aa0342.media.strapiapp.com/Strapi_full_logo_dark_971ef90efc.svg (linked from https://strapi.io/) | https://handbook.strapi.io/strapi-brand-book-2022/strapi-logo — retain the complete logo, colors, proportions, and clear space |
| meshery.svg | https://meshery.io/assets/images/brand/meshery-logo-and-text-light.svg | https://meshery.io/brand/ — retain the original mark and avoid confusing usage |

Infisical, Lightdash, ToolJet, and Automatisch appear as text links. Follow the
linked brand guidance and reassess these references when replacing assets.

Assets are served locally under `project-logos/`, including under a configured
Vite base path. They require no new CSP origins (`img-src 'self'` already applies).
